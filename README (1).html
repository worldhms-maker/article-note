앤트로픽 IPO 블로그 콘텐츠 프로젝트

앤트로픽 IPO를 주제로 블로그 포스팅과 파생 콘텐츠를 제작하는 프로젝트입니다.

개요

  • 주제: 앤트로픽 IPO
  • 주요 산출물: 블로그 포스팅
  • 파생 콘텐츠: 뉴스레터(20대 직장인 대상), 인스타그램 카드뉴스(8장)
  • 제작 방식: 생성형 AI(Claude) 활용

참고 자료

  • PDF 'ai money map 01~05'
  • 제목은 위 자료의 제목을 참고해 2가지 안으로 작성합니다.

구분대상분량상태

작업 순서

  1. 참고 자료(PDF) 내용 정리
  2. 제목 2가지 안 선정
  3. 블로그 본문 초안 작성
  4. 뉴스레터·카드뉴스로 재구성
  5. 수치·날짜 출처 확인 후 최종 검수

작성 원칙

  • 수치와 날짜는 출처를 함께 적습니다. 출처가 없으면 "확인 필요"로 표시합니다.
  • IPO 일정과 금액 등 최신 정보는 작성 시점 기준일을 함께 적습니다.
  • 개인정보와 내부 기밀은 포함하지 않습니다.
