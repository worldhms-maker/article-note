AI 콘텐츠 크리에이터 페이지

40대를 위한 AI 쇼츠 채널의 소개 페이지와, 기사 프로젝트용 노트 페이지를 담은 저장소입니다. 빌드 없이 HTML 파일을 브라우저로 열면 바로 보입니다.

파일 구성

파일설명
creator-intro.htmlAI 콘텐츠 크리에이터 한 장짜리 소개 페이지
project-note.html기사 프로젝트 노트 (브리프, 팀, 주제, 할 일 5개, 날짜별 기록)

사용 방법

  1. 저장소를 내려받습니다. 
    git clone <저장소 주소>
  2. 원하는 .html 파일을 더블클릭하거나 브라우저로 끌어다 놓습니다.

수정할 곳

  • creator-intro.html: 구독 버튼의 href="#"를 채널 주소로 바꿔 주세요. 채널 주소는 확인 필요입니다.
  • project-note.html: 칸에 직접 적으면 해당 기기의 브라우저에 자동 저장됩니다. 다른 기기로는 옮겨지지 않습니다.
